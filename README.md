# 🚀 Features

<div align="center">

| # | Feature | Description |
|:---:|---|---|
| `01` | 📄 **Create File** | Create a new file from the terminal |
| `02` | 📋 **Copy File** | Copy files to another location |
| `03` | 🗑️ **Delete File** | Remove files or directories |
| `04` | ✏️ **Rename File** | Rename an existing file |
| `05` | 📦 **Move File** | Move files between locations |
| `06` | 🔍 **Inspect** | View file/directory information |
| `07` | 📁 **Create Folder** | Create a new directory |
| `08` | ✅ **Validate Folder** | Check whether a directory exists |
| `09` | 📂 **Browse Folder** | Display directory contents |
| `10` | 🔎 **Find Files** | Search files by name |
| `11` | 🔤 **Search Text** | Search text recursively inside files |
| `12` | 🧩 **Filter Files** | Find files by extension |
| `13` | 🔢 **Count Files** | Count files and directories |
| `14` | 📊 **Analyse Directory** | Analyse files, directories and disk usage |
| `15` | 🚪 **Exit** | Safely exit the application |

</div>
